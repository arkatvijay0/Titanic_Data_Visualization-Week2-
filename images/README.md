# 📊 Visualization Outputs


This folder contains the visualization outputs generated using R and ggplot2 for the Titanic Data Visualization project.

The graphs were created using the cleaned Titanic dataset and are used to communicate important patterns, trends, comparisons, and relationships.

---

## 📈 Visualization List

| No. | Visualization | Chart Type | Purpose |
|---:|---|---|---|
| 1 | Titanic Passenger Survival Distribution | Bar Chart | Shows overall survival distribution |
| 2 | Titanic Survival Distribution by Gender | Grouped Bar Chart | Compares survival counts by gender |
| 3 | Titanic Survival Rate by Gender | Bar Chart | Compares survival percentages by gender |
| 4 | Age Distribution of Titanic Passengers | Histogram | Shows passenger age distribution |
| 5 | Titanic Passenger Distribution by Class | Bar Chart | Compares passenger numbers across classes |
| 6 | Titanic Survival Distribution by Passenger Class | Grouped Bar Chart | Compares survival across classes |
| 7 | Relationship Between Passenger Age and Fare | Scatter Plot | Examines age-fare relationship |
| 8 | Age Distribution by Survival Status | Box Plot | Compares age distributions of survivors and non-survivors |
| 9 | Fare Distribution by Survival Status | Box Plot | Compares fare distributions by survival |
| 10 | Titanic Survival Rate by Age Group | Bar Chart | Compares survival rates across age groups |
